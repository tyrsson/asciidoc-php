All API endpoints follow REST conventions. Requests and responses use JSON. Authentication uses Bearer tokens (see xref:authentication.adoc[Authentication]).

Base URL

https://api.example.com/api/v1

All paths in this document are relative to the base URL.

Authentication

Include the Bearer token in all requests:

GET /api/v1/users HTTP/1.1
Host: api.example.com
Authorization: Bearer eyJhbGciOiJIUzI1NiJ9...
Accept: application/json

POST /api/v1/users HTTP/1.1
Content-Type: application/json

{
    "name":     "Carol White",
    "email":    "carol@example.com",
    "password": "SecurePass123!",
    "role":     "editor"
}

Returns 201 Created with the created user.

Update User

PUT /users/{id}

Accepts the same fields as Create User. All fields are optional in a PUT (unset fields are left unchanged).

Delete User

DELETE /users/{id}

Returns 204 No Content on success.

Deleting a user is irreversible. All user data including audit logs and assigned resources will be permanently removed.

{
    "app_name":          "My Application",
    "app_url":           "https://myapp.example.com",
    "mail_from_address": "noreply@myapp.example.com",
    "mail_from_name":    "My Application",

Changing app_url may invalidate existing signed URLs and OAuth redirect URIs. Update these in your OAuth provider settings as well.

Supported events:

Event

Triggered When

`user.created`

A new user account is created

`user.updated`

A user account is updated

`user.deleted`

A user account is deleted

`post.published`

A post status changes to `published`

`post.unpublished`

A post is moved back to `draft` or `archived`

`post.deleted`

A post is permanently deleted

`settings.updated`

Application settings are changed

`webhook.failed`

A webhook delivery attempt failed

Webhook Payload

{
    "id":         "evt_abc123",
    "event":      "user.created",
    "created_at": "2026-01-22T10:00:00Z",
    "data": {
        "id":    42,
        "name":  "New User",
        "email": "newuser@example.com"
    }
}

Verify the HMAC signature:

$signature = $request->header('X-Webware-Signature');
$payload   = $request->rawBody();
$expected  = 'sha256=' . hash_hmac('sha256', $payload, $secret);

if (! hash_equals($expected, $signature)) {
    return new Response(401);
}
